Elhai Family Reunions
Gift program

To download program that will tell you who you're matched with:

  • Click here and navigate to the directory of your choice. Then click OK to download the program.
  • Click here to download data for the program (e.g. everyone's names). If weird symbols appear instead of a Save as box, then click File (left hand corner), then Save as, then OK.
To run the program:
  • Find gifts.exe on your computer, whatever directory you saved it in.
  • Double click it to run the program.
  • If you're asked for a new password, make up something.
  • If you're asked for a password (not new), then you've already given the program a password. If you don't remember it, contact me.
